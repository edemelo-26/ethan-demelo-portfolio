# Ethan DeMelo — Portfolio

Personal GIS portfolio, built for the GEOG 476 S07 studio and future use.

Live website: https://edemelo-26.github.io/ethan-demelo-portfolio/

GitHub Pages publishes the main branch, root folder (/), with HTTPS.

## Pages

- index.html — name, headline and one featured project
- about.html — background, experience and GIS Technician goal from the supplied resume
- projects.html — three project cards, each linking to its own page
- project-1.html — Vending Machine Tracker, source-point Leaflet map and table
- project-2.html — county-level population cartography and supplied StoryMap embed
- project-3.html — coastal wetland classification and original lab figure
- resume.html — web overview of education, experience, projects and skills; resume.pdf — original completed resume assignment PDF
- style.css — shared responsive layout, navigation, focus and print styles

Every page has Home / About / Projects / Resume navigation and a footer without personal contact information. All site paths are relative for GitHub Pages project hosting.

## Sources and remaining content fields

Facts and figures come from the supplied resume and coursework. The two [ADD] fields identify information absent from the project reports: the ACS estimate vintage and the coastal imagery sensor/acquisition date. No missing facts were guessed.

The StoryMap may require ArcGIS sign-in; the embed has an original-link fallback. Leaflet 1.9.4 loads from unpkg and the interactive map uses Esri World Topographic Map tiles. The eight GNSS records include two buildings sharing one source coordinate; this is documented and preserved. The original map and coordinate table remain available when JavaScript or the map library cannot load.

The downloadable resume uses the original resume assignment with contact links, phone/email and location fields permanently redacted at Ethan’s request. The original assignment is unchanged outside this repository. Other source assignment documents remain outside this repository. Assignment resources, AI notes and review logs remain in the parent Portfolio Assignment folder. No named reviewer persona results are claimed.

Ethan authorized AI drafting for the in-class build and then explicitly asked to finish continuously, overriding the slide's one-file-per-reply instruction.

## Visual design

Fixed dark interface with black surfaces, Aggie maroon (#500000), an original survey mark and source-point schematic, layer display controls, and shared responsive typography. The vector artwork comes from the portfolio’s own GNSS records. Original coursework figures and the redacted resume PDF retain their source content.
