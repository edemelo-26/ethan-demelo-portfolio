How to read the stages

A completed work order records its defined contribution. A larger research problem can retain a further review or validation stage after a useful audit, reproduction or reviewed package has been delivered. The entries state those outcomes directly.

Each entry is backed by saved project source and result artifacts. The portfolio audit also reconciled received and sent package versions with the Hub’s current Drive folders. It preserves corrections, earlier versions and overlap rather than counting each transport copy as new research.
